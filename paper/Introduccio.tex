\chapter{Introduction}

\section{Contextualization}

Minecraft can be played in either single-player or multiplayer mode. In multiplayer, the game running on the user’s machine acts as a client that connects to a server. Players seeking minigames or interaction with larger communities generally join public servers, many of which are commercially operated and generate revenue through advertising, paid ranks, or gameplay advantages. Players who want a private experience closer to the original game can instead rent a server from a hosting provider or host one on their own machine. Commercial hosting simplifies the process but usually requires a recurring subscription, whereas self-hosting provides greater privacy and control at the cost of increased technical complexity.

The ecosystem of Minecraft client launchers is active and mature: Mojang and the community provide solutions for different users, requirements, and levels of technical knowledge. By comparison, tools for creating and managing self-hosted servers have received less attention. This may be because users interested in self-hosting have traditionally been assumed to possess enough technical knowledge to configure a server manually. Consequently, casual players have relatively few tools that combine ease of use with the functionality required to manage a complete Minecraft server.


\section{Motivation}
Creating a Minecraft: Java Edition server manually involves coordinating several interdependent components. Users must download the appropriate server files, ensure that a compatible Java runtime is installed, and edit text-based configuration files. Modded servers introduce further complexity: users must install a compatible mod loader, download each mod individually, and resolve conflicts between Minecraft, the mod loader, and the selected mods until the server starts correctly.

Making the server accessible outside the local network introduces another significant obstacle. Minecraft: Java Edition servers listen on TCP/UDP port 25565 by default, so users commonly need to access their router's configuration and permit incoming connections. This step is unfamiliar to many casual users and frequently prevents them from completing the server setup process.

Server maintenance presents similar difficulties. When migrating to a newer Minecraft version, users must update not only the base server but also the mod loader and every installed mod. Existing files often need to be removed or replaced manually, after which compatibility problems must be identified and resolved again. These repetitive and error-prone tasks create an unnecessary barrier for players who want a private server but lack server-administration experience.


\section{Objective}

The objective of the Wave Launcher is to enable casual players to create and manage private, self-hosted Minecraft: Java Edition servers without paying recurring hosting fees or requiring advanced technical knowledge. The application should provide a simple and intuitive interface that guides users through server creation, configuration, network setup, and maintenance.

The Wave Launcher should internally coordinate the server software, Java runtime, mod loader, and installed mods so that users do not need to manage these components manually. It should also assist with compatibility resolution and version migrations, ensuring that the required components remain correctly configured when a server is created or updated. Ultimately, the application aims to make self-hosting accessible while preserving the privacy, control, and flexibility that motivate users to operate their own servers.
